# 朋友游戏厅

一个部署在自己服务器上的私人游戏平台：统一账号登录，在首页的「游戏柜」里选择游戏。
目前收录的游戏：**卡坦岛**（`/catan/`）、**猛鬼宿舍**（`/dorm/`）、**工业革命：伯明翰**（`/brass/`）。

## 平台

- 首页 `/`：登录（账号由管理员开通，无需密码）后进入游戏大厅，显示在线人数、各游戏进行中的房间和你的战绩；
  在大厅里也能收到朋友的游戏邀请。
- 管理员后台 `/admin`：管理整个平台的账号。
- 平台名称可在 `.env` 中设置：`PLATFORM_NAME=你喜欢的名字`。
- 旧的卡坦岛邀请链接（`/?room=XXXXX`）会自动跳转到 `/catan/`。
- **全屏游玩**：首页、各个游戏的首页 / 房间 / 对局画面右上角都有全屏按钮（像手机上全屏看视频一样，再点一次退出）。
  打开全屏后在页面之间跳转（例如从大厅进入游戏）会记住这个选择，到新页面点一下屏幕就回到全屏；按返回键或 Esc 退出后不再自动进入。
  iPhone 的 Safari 不支持网页全屏，按钮会提示「分享 → 添加到主屏幕」，之后从桌面图标打开就是全屏（`public/manifest.webmanifest`）。

### 添加新游戏

1. 服务器：在 `server/games/<id>/index.js` 导出 `createGame(platform)`，返回
   `{ id, handlers, routes, onConnect, onClose, kickUser, summary, shutdown, rateKey }`（可参考卡坦岛模块）。
2. 在 `server/index.js` 的 `GAMES` 与 `CATALOG` 中登记，并在 `WS_ROUTES` 加上 `/<id>/ws`。
3. 前端：页面放在 `public/<id>/`，用 `/js/session.js` 获取登录状态，未登录时调用 `goToLogin()`。
4. 战绩写入 `matches` 表时带上 `game: '<id>'`。

## 卡坦岛

网页端卡坦岛，支持 4 / 6 / 8 人地图、好友联机、电脑玩家、动画与合成音效，
以及账号登录、战绩排行榜和管理员后台。
服务端与前端均为原生 JavaScript，数据保存在 SQLite（Node 内置 `node:sqlite`），
**没有任何第三方依赖**，不需要 `npm install`。

## 猛鬼宿舍

合作塔防（也叫「躺平发育」）：熄灯后猛鬼出没，玩家各占一间宿舍躺下发育、造防御守门，坚持到天亮。
支持 1–8 人联机，可以加电脑或智谱 AI 队友；恐怖风格的画面、配乐与音效全部由程序实时绘制 / 合成，
手机竖屏、横屏和电脑都能玩。

**玩法**

- 开局所有人都在宿舍楼入口（走廊尽头的安全出口）集合。点地面走动（电脑上也可以用 W/A/S/D 或方向键），
  走进一间空宿舍、**躺到床上**就占下了这间——一间只能住一个人，有人躺下后门就关上，屋里的其他人会被请出去。
  猛鬼醒来时还没躺下的人，会吓得钻进离自己最近的空宿舍。
- **每局地图随机**：8 间宿舍的宽度、进深、门和床的位置都不一样，有的缺一个角，有的摆着衣柜、书桌、书架
  （不能建造）。生成时保证面积在合理范围（14–30 格地面、至少 10 格能建造），从门口能走到每一块地面和床边。
  地板花色也各不相同。
- **每间宿舍随机刷 1–3 个初始道具**：可以搜的旧储物柜（随机给金币或电池），或免费的 1 级建筑。
- 床每秒产金币，升级**床**提高收入；升级**门**加血。高级升级需要**电力**，造发电机产电。可以建造 13 种道具：

  | 道具 | 作用 |
  | --- | --- |
  | 桃木弩 | 自动射击范围内的猛鬼 |
  | 天雷符 | 蓄力后降下天雷，单发伤害极高 |
  | 铜钱剑 | 射程短、出手快，飞剑来回斩击 |
  | 火符阵 | 射出火符，让猛鬼持续灼烧（无视护甲） |
  | 捕鬼夹 | 猛鬼靠近时夹住并重创，放在门后最好 |
  | 寒冰棺 | 让范围内的猛鬼移动和攻击变慢 |
  | 镇魂铃 | 定时摇铃，把范围内的猛鬼定住（之后有短暂免疫） |
  | 照妖镜 | 猛鬼砸本房门时反弹部分伤害 |
  | 引魂灯 | 周围一圈的攻击建筑伤害提高 |
  | 符水台 | 持续修门 |
  | 香案 | 持续修补屋里被砸坏的道具，并让道具更结实 |
  | 招财猫 | 每秒额外招来金币 |
  | 发电机 | 产电 |

  靠门的防御能打到门外的猛鬼，隔壁和对面宿舍的防御也能互相支援。建筑可以升级，拆除返还一半花费。
- 猛鬼醒来后挑一间宿舍砸门。**门破之后**，它会挑一条「砸开最快」的路线，一路把挡路的道具砸烂，走到床边——
  **床边挨一下就出局**（人和床都没有血量，也没有补血的道具），所以屋里道具的摆法就是最后一道防线。每个道具都有耐久，香案能修补并加固屋里的道具。猛鬼每隔一段时间升一级，
  伤害和**护甲**越来越高（每发伤害先减去护甲，低级弩堆数量不划算），血少了会回血池回血。
- 倒计时结束（天亮）时还活着就算胜利；也可以直接把猛鬼打死。

**动画**：弩箭后坐与拖尾、飞剑来回斩击、火符抛物线与灼烧火焰、带分叉的天雷与焦痕、捕鬼夹合拢与铁链、
镇魂铃摆动与金色波纹（猛鬼额头贴符）、照妖镜反光、寒冰棺飘雪、符水台/香案的修补光点、招财猫招手掉金币、
发电机电火花、引魂灯光链、建造弹出与升级光柱、储物柜金币喷涌、猛鬼抓痕、门被砸时抖动、躺下盖被子、睡觉的 Zzz。

**难度**

| 难度 | 时长 | 猛鬼 |
| --- | --- | --- |
| 简单 | 6 分钟 | 随便挑人，又慢又脆 |
| 普通 | 8 分钟 | 爱挑门最破的宿舍 |
| 困难 | 9 分钟 | 会算计：挑最好打的、打不动就换人、提前撤退，还会「鬼哭」让一间宿舍的防御停摆 3 秒 |
| 噩梦 | 9.5 分钟 | 护甲厚、成长快、更频繁的鬼哭，建议和高手队友一起 |

人越多猛鬼血越厚；一两个人玩时猛鬼伤害打折。各难度用电脑对局调过平衡（`node test/dorm-sim.js balance`）。

**电脑与 AI 队友**

- 内置电脑分三档：**菜鸟**（反应慢、常乱买）、**老手**、**大神**（会攒钱、按威胁调整经济与防守）。
  思路与卡坦岛的内置电脑相同：列出所有可做的事，估算每块金币的价值再挑最好的。
- 配置了智谱 Key 时可加 **智谱 AI** 队友：模型每 20 秒左右根据局势定一次侧重（经济 / 防守 / 输出 / 均衡）
  并在聊天里说一句台词，具体建什么、放哪里由内置策略按侧重来算；出错或超时保持原侧重，不会卡住。
  与卡坦岛共用同一个智谱配置和用量统计。
- 真人掉线 15 秒（`DORM_AFK_MS`）后由电脑代管，重新连上自动交还。

**操作**：准备阶段点地面走动、点空床躺下；躺下后点格子建造 / 升级 / 拆除 / 搜柜子，底部按钮升级床和门；
建造面板里**长按**（电脑上右键）道具看每一级的花费、效果和耐久；「怎么玩」里有完整的道具图鉴。
双指或滚轮缩放、拖动平移，右上角切换「跟着我 / 我的宿舍 / 全图」。
电脑上的快捷键：W/A/S/D 或方向键走路，B 升床，D 升门（躺下后），F 切换视角，U 升级选中建筑，1–9 在选中格建造，Esc 关闭。

对局是实时的（服务器每 100 毫秒推进一次），只保存在内存里；服务器重启时进行中的猛鬼宿舍对局会结束。
战绩与排行榜和卡坦岛分开记录（按「活到天亮」的局数排名）。

## 工业革命：伯明翰

以英格兰中部的工业革命为背景的经济策略游戏（玩法参照桌游 Brass: Birmingham），2–4 人，
分**运河时代**和**铁路时代**两个时代。地图、板块、音乐与音效全部由程序绘制 / 合成，没有图片和音频文件。

**玩法**

- 22 座城镇（含两座郊外酒坊）、5 个商人、39 条线路（基德明斯特—伍斯特那段途经南郊酒坊）；3 人局起开放北部城镇和沃灵顿，4 人局再开放贝尔珀、德比与诺丁汉。
  商人板块按人数（2 / 3 / 4 人：5 / 7 / 9 块）每局随机摆放。
- 数值与官方一致：产业板块（造价、煤铁、啤酒、分数、收入、线路图标、仅运河 / 仅铁路 / 灯泡）、牌堆构成（40 / 54 / 64 张）、
  商人板块、市场价格、收入轨、各商人的啤酒奖励。对照了官方规则书与 Tabletop Simulator 模组的数据。
- 每轮每人 2 个行动（运河时代第 1 轮只有 1 个），每个行动弃 1 张手牌：**建造**、**修建网络**（运河 / 铁路，可一次修两段铁路）、
  **开发**、**出售**、**贷款**、**侦察**、**跳过**。本轮花钱最少的人下一轮先行动，每轮结束按收入等级领钱（负收入要付钱，付不起要卖厂、扣分）。
- 完整规则：地点牌 / 产业牌 / 万能牌、「你的网络」、运河时代每城一座、单图标格子优先、覆盖建造（含市场与场上都没有煤 / 铁时覆盖别人的矿）、
  煤从连通的最近煤矿拿（否则要连到商人才能从市场买）、铁不需要连通、啤酒（自己的 / 连通的别人的 / 商人的，商人啤酒带奖励）、
  煤矿连通商人与炼铁厂建好时把方块卖给市场、拿空即翻面、收入轨、线路按两端图标计分、运河时代结束拆掉运河与Ⅰ级工厂、
  「仅运河」/「仅铁路」与灯泡板块。
- **入门短局**（房间里勾选）：只玩运河时代，结束时额外按现金（每 £4 一分，最多 15）、收入等级和Ⅱ级以上翻面工厂计分。
- 行动的每个来源（用了谁的煤、谁的啤酒、市场花了多少）在确认面板里都写清楚，地图上点任何城镇 / 工厂 / 商人 / 线路可以查看说明。
  「提示」按钮会让内置电脑给你推荐一步，可以一键照做。

**新手教程**：首页的「新手教程」开一个私人房间，导师老约翰（电脑）陪你打，固定开局。28 步引导（遮罩 + 聚光灯 + 气泡讲解，
可开关的中文语音朗读）：认识界面 → 在伯明翰建棉纺厂 → 贷款 → 修运河连到牛津 → 出售翻面拿商人奖励 → 建煤矿 → 进阶要点，
之后整局自由打完。走偏了会自动接上，刷新页面能从当前步骤继续。教程不计战绩。

**电脑与 AI 玩家**：内置电脑分三档：**学徒**、**工头**、**大亨**。思路是列出所有合法行动，在副本上试走一步，
用局面估值（分数、按翻面概率折算的工厂价值、线路图标、收入 × 剩余轮数、手上的钱）比较好坏。
配置了智谱 Key 时可加 **AI 玩家**：程序给出估值前 6 名的候选，模型挑一个并说一句台词，出错或超时由内置策略决定。
与卡坦岛共用同一个智谱配置和用量统计。

**动画**：工厂落地弹跳与尘土、煤块 / 铁块 / 啤酒桶沿抛物线从来源飞到工地、市场方块与金币进出、翻面（翻转 + 金光 + 收入飘字）、
运河一路「流」过去并有小船驶过、铁路一路铺过去并有冒蒸汽的小火车、货箱飞向商人、开发时板块飞走、贷款金币雨、
行动顺序变化时玩家卡片滑到新位置、时代结束逐条线路 / 逐座工厂计分、运河填平与Ⅰ级工厂坍塌、铁路时代的过场（蒸汽火车横穿屏幕）、
胜利烟花与彩带、地图上工厂冒烟与运河水光。系统开启「减少动态效果」时自动简化。

**音乐与音效**：运河时代是 3/4 拍手风琴华尔兹，铁路时代是带「哐当」节奏的进行曲；铁锤敲砧、煤块滚落、铁水叮当、
啤酒桶、水声与船桨、蒸汽与铁轨、收银机、齿轮棘轮、工厂汽笛（轮到你）、钟楼报时（一轮结束）、长汽笛（时代结束）、铜管号角（胜利）。

**语音**：与卡坦岛相同的房间语音（声网或内置 WebRTC），教程房间里也能用。

**AI 语音（智谱 GLM-TTS）**：配置了智谱 Key 时，导师的教程讲解和 AI 玩家在聊天里说的台词会用接近真人的语音念出来
（导师一个音色，每位 AI 玩家按座位分配不同音色）。服务器代为调用接口（Key 不会发给浏览器），
每句话按「文本 + 音色 + 语速」缓存成 wav 文件（`data/tts-cache/`，默认最多 300 MB），同一句只生成一次——
教程的固定台词生成一次后就不再花钱。下一步的讲解会提前生成，翻页不用等。
没有配置、接口出错或超时时自动改用浏览器自带的朗读。游戏内「♪」设置里可以分别开关教程讲解、AI 台词朗读，调节语音音量。
智谱默认会给合成的语音加水印；如果在开放平台设置了去水印，语音里就不会有。

**手机**：竖屏时玩家在顶部一条、手牌和行动按钮在底部，地图默认铺满可拖动（⌂ 切换整张地图 / 铺满）；
横屏（例如全屏后）手牌在左、行动在右、中间是地图。双指缩放，确认面板从底部弹出。

**快捷键**：B 建造，N 网络，D 开发，S 出售，L 贷款，H 提示，M 产业板，Esc 取消，+ / − 缩放，0 切换视角。

对局实时写入数据库（与卡坦岛共用 `rooms` 表，键名带 `brass:` 前缀），部署或重启后自动恢复。战绩与排行榜单独记录。

## 房间语音

进入房间后自动加入该房间的语音频道：**扬声器默认打开，麦克风默认关闭**，
点右上角的麦克风按钮开始说话；正在说话的玩家头像会发光。

- **声网 Agora（推荐）**：在声网控制台创建项目（鉴权方式选「App ID + Token」），
  把 App ID 和 App 证书写进服务器的 `.env`：
  ```bash
  AGORA_APP_ID=你的AppID
  AGORA_APP_CERTIFICATE=你的App证书
  ```
  服务器会为每位玩家签发 24 小时有效的 Token（证书不会发给浏览器）。
  声网 Web SDK 在 Docker 构建时下载到本站，玩家从你的服务器加载。
- **未配置声网时**：使用内置的 WebRTC 点对点语音；跨运营商、手机网络下可能连不通。
- **麦克风必须在 HTTPS 下使用**：这是浏览器的限制，与语音服务商无关。
  通过 `http://IP` 访问时只能收听，不能说话。

## AI 玩家（智谱大模型）

房主在大厅可添加两种电脑玩家：**内置电脑**（程序策略，反应快）和 **AI 玩家**（智谱大模型做关键决策）。
在服务器 `.env` 中加入后 `./deploy.sh` 即可启用：

```bash
ZHIPU_API_KEY=你的智谱APIKey
# 可选：默认 glm-4.7-flash（免费）；想更强可换 glm-4.7 / glm-5-turbo 等付费模型
ZHIPU_MODEL=glm-4.7-flash
# 可选：设为 1 开启深度思考（更聪明，但每步慢很多、token 多）
ZHIPU_THINKING=
```

- 程序先算出合法且排好序的候选（位置价值、资源点数、港口、对手威胁），模型只在关键时刻做选择：
  开局选点、每回合的行动计划、强盗位置与偷谁、是否接受交易。掷骰、弃牌等机械步骤沿用内置策略。
- 提示词精简（每次约 400–600 个汉字），模型以 JSON 回答；回答无效、超时或出错时自动回退到内置策略，对局不会卡住。
- 管理员后台显示 AI 调用次数、失败次数与 token 消耗。

## 账号与管理员

- 玩家必须用账号登录才能进入，**账号不需要密码**，由管理员在后台开通。
- 管理员后台：`http://服务器地址/admin`，用环境变量 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 登录。
  **不要把密码写进代码或提交到仓库**，写在服务器项目目录下的 `.env` 文件里：
  ```bash
  CATAN_PORT=80
  ADMIN_USERNAME=你的管理员账号
  ADMIN_PASSWORD=你的管理员密码
  ```
- 管理员可以批量添加账号、启用 / 禁用、删除。禁用或删除后，该玩家立即被强制下线；
  正在进行的对局由电脑接管。删除账号后，历史战绩里仍保留其名字。
- 管理员登录 12 小时后过期；玩家登录 180 天内有效。

## 快速部署（Docker）

```bash
# 在服务器上，进入项目目录
docker compose up -d --build
# 浏览器访问 http://服务器IP:3000
```

修改对外端口：`CATAN_PORT=8080 docker compose up -d --build`

不用 compose 时：

```bash
docker build -t catan-online .
docker run -d --name catan -p 3000:3000 --restart unless-stopped catan-online
```

> 国内服务器拉取 `node:22-alpine` 较慢时，可在 `/etc/docker/daemon.json` 配置镜像加速，
> 或把 Dockerfile 第一行改成可用的镜像源地址（例如公司内部仓库中的 node:22-alpine）。

### HTTPS（麦克风需要）

仓库自带 Caddy 配置，可直接用 **Let's Encrypt 的 IP 地址证书**（6 天有效，Caddy 自动续期），不需要域名。
在服务器的 `.env` 中加入：

```bash
COMPOSE_PROFILES=https
PUBLIC_IP=你的服务器公网IP
CATAN_BIND=127.0.0.1
CATAN_PORT=3000
TRUST_PROXY=1
```

然后 `./deploy.sh`。防火墙需放行 TCP 80 和 443。`http://` 仍可访问；
网页检测到 HTTPS 可用后会自动跳转过去，并保留登录状态。
查看证书申请情况：`docker compose logs caddy | grep -iE "obtained|error"`。

若改用自己的 Nginx，参考 `nginx.conf.example`（必须转发 WebSocket 的 `Upgrade` 头）。

### 不用 Docker

需要 Node.js 22.13 以上：

```bash
ADMIN_USERNAME=admin ADMIN_PASSWORD=xxx npm start
```

## 自动部署（GitHub Actions）

推送到 `main` 分支后，Actions 会先运行测试，通过后 SSH 到服务器执行
`git reset --hard origin/main && ./deploy.sh`。

**一次性准备**

1. 服务器上克隆代码并写好端口配置：
   ```bash
   git clone https://github.com/skyofish/catan-online.git ~/catan
   echo "CATAN_PORT=80" > ~/catan/.env
   ```
2. 服务器上生成一把专用于部署的密钥，并允许它登录：
   ```bash
   ssh-keygen -t ed25519 -f ~/.ssh/github_deploy -N "" -C github-actions
   cat ~/.ssh/github_deploy.pub >> ~/.ssh/authorized_keys
   cat ~/.ssh/github_deploy      # 复制输出的全部内容，下一步要用
   ```
3. 在 GitHub 仓库 Settings → Secrets and variables → Actions 添加：

   | Secret | 值 |
   | --- | --- |
   | `SSH_HOST` | 服务器 IP |
   | `SSH_KEY` | 上一步输出的私钥全文（包括 BEGIN / END 行） |
   | `SSH_USER` | 可选，默认 `ubuntu` |
   | `SSH_PORT` | 可选，默认 `22` |
   | `DEPLOY_PATH` | 可选，默认 `~/catan` |

之后每次推送都会自动部署；也可以在 Actions 页面手动点 “Run workflow”。
手动部署：在服务器上 `cd ~/catan && git pull && ./deploy.sh`。

## 玩法功能

- **地图**：4 人经典 19 块；6 人扩展 30 块；8 人大岛 43 块。地形、数字、港口每局随机生成，自动避免 6 和 8 相邻。
- **完整规则**：初始放置（蛇形顺序，第二个村庄发资源）、距离规则、掷 7 弃牌与强盗、偷牌、
  银行 4:1 与 3:1 / 2:1 港口、玩家间报价交易、五种发展卡（本回合买的不能用、每回合限一张）、
  最长道路（含被截断的重新计算）、最大军队、银行资源不足时不发放、目标分数可设 8–14。
- **6 / 8 人特殊建造阶段**：每名玩家结束回合后，其余玩家依次获得只能建造的机会（可在房间里关闭）。
- **地图预览**：房间大厅里预览本局地图，房主不满意可以「换一张」，开局就用这张。
- **邀请**：在房间大厅里可看到所有在线玩家（空闲 / 在房间中 / 对局中），一键邀请；对方收到弹窗后可直接加入或忽略。
- **联机**：房间号 + 邀请链接；刷新、断网或主动离开后都能回到原座位（离开期间电脑代打）；满员或开局后进入观战；
  房主可添加电脑玩家、移出玩家、让离线玩家由电脑代管；结束后一键回到房间再来一局。
- **动画**：地块落下开场、3D 骰子、产出地块闪光与资源卡飞入手牌、建筑落下弹跳与粒子、
  强盗跳跃移动、偷牌/交易/垄断时卡牌在玩家之间飞行、发展卡翻转展示、回合横幅、
  奖励金光、胜利彩带与骰子点数分布图。系统开启"减少动态效果"时自动简化。
- **音效**：全部由 Web Audio 实时合成（不需要音频文件）——骰子滚动、修路、建村庄、城市、
  各资源不同音色、强盗、掷出 7、偷牌、交易、发展卡、骑士号角、轮到你的钟声、胜利号角，
  以及可开关的生成式背景音乐。音量在右上角 ♪ 中调节。
- **快捷键**：R 掷骰，E 结束回合，T 交易，1–4 建造，Esc 取消，+ / − 缩放，0 复位视角。
- **手机**：竖屏可玩，双指缩放棋盘，玩家列表与聊天为侧边抽屉。横屏（例如全屏后）时手牌和发展卡在左边、建造与回合按钮在右边，中间整块是地图。
- **战绩**：每局结束自动记录；首页有排行榜（按胜场、胜率排序）和「我的战绩」（最近 10 局）。
- **续玩**：进行中的对局实时写入数据库，部署或重启后自动恢复，玩家刷新页面即可回到原座位。

## 说明

- 数据库保存在 Docker 数据卷 `catan-data` 中，重建镜像、重启容器都不会丢失。
  备份（在线一致性快照）：
  ```bash
  docker compose exec catan node -e "new (require('node:sqlite').DatabaseSync)('/app/data/catan.db').exec(\"VACUUM INTO '/tmp/backup.db'\")"
  docker compose cp catan:/tmp/backup.db ./catan-backup-$(date +%F).db
  ```
- 单个进程即可支撑大量房间；如需多实例横向扩展，需要在负载均衡上开启会话保持（同一房间的玩家连到同一实例）。
